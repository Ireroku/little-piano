# 小さなピアノ

ブラウザで弾ける25鍵のピアノです。音は Web Audio API で合成しています。

`index.html` をブラウザで開いてください。ビルドは不要です。

鍵盤をクリック、タップ、またはドラッグして弾けます。PC のキーボードでは、鍵盤に表示された文字・数字のキーを使います。既定の表示では、C4〜B4 は Z〜M、C5〜C6 は Q〜I です。

「曲を流す」を押すと、このピアノのために作ったオリジナルの旋律「小さなワルツ」が流れます。再生中も鍵盤を弾けます。

手弾きでは音の高さや同じ鍵を続けて弾く間隔に応じて、少しずつ強弱がつきます。自動演奏ではフレーズの流れや拍に合わせて強弱がつきます。自動で強めについた音ほど、音量が上がり、音色も明るくなります。
